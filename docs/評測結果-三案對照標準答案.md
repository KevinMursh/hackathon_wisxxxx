## 評測設計（為什麼可信）

| 項目 | 做法 |
|---|---|
| 測試案來源 | 法制局提供的 101 份歷史決定書中挑 3 份（不受理／駁回／撤銷各一），**反推出完整卷宗包**（訴願書、答辯書、卷證共 30 頁，含掃描件、照片、手寫切結書、影片） |
| 防作弊 | 這 3 份決定書**從知識庫（RAG）與相似案例排除**；系統只看卷宗，看不到答案 |
| 標準答案 | 決定書的主文、條款、相關法條、理由段論證點（`04-標準答案.md`）；送達／收文日期（`03-卷宗清單.md`） |
| 比對方式 | 程式自動逐項比：期間三日期、法條命中、相似案例是否混入本案、主文條款、論證點關鍵字 |
| 跑法 | 三案由首頁示範卡真跑：Claude 逐檔辨識類型與來源（不看檔名）→ 五步分析 → 決定書草稿；每案 4–5 分鐘 |

## 最值得講的一案：case03

決定書的撤銷理由——**行政罰法 §27 裁處權三年時效已過**——是委員會依職權自己發現的，訴願人的答辯書沒主張到重點、機關答辯書更只說「複查時才發現」。

系統做到了三件事：
1. 從卷宗算出 111-06-09 行為終了 → 114-06-08 時效屆滿 → 114-07-04 才裁處，逾 26 日
2. 把時效列為第一爭點並採訴願人，其餘實體爭點（簽證是否不實）仍採機關——**不是偏袒訴願人，是依法**
3. 主文寫「原處分撤銷」而非「撤銷另為處分」（時效消滅就沒有再處分空間），且**不附行政訴訟教示**——這是決定書格式上最容易錯的細節

## 誠實揭露（投影片下方小字）

- Tab2 爭點清單沒有「正解」可比；能確認的是關鍵爭點與認定方向與決定書一致
- 論證點涵蓋是關鍵字比對：三個「缺」都是「該引而未引」的次要法條（行政程序法 §72／§73、車籍資料、申報辦法附表 1），不是判斷錯誤
- 相似案例只能驗「未混入本案自身」與「同法」，相似度分數無正解
- 評測過程修掉兩個草稿問題：全部勝訴案誤附教示；草稿抄入範例決定書的真實委員姓名 → 現已程式強制占位
