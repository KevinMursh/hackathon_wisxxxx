# 提案大綱

## 中文（293 字）

訴願智審臺——承辦人的AI審卷夥伴。承辦人只需將訴願書、答辯書與卷證原樣上傳，系統以Amazon Bedrock（Claude Sonnet 4.5）自動辨識27類文件並命名，再執行固定七步驟：讀基本資料、程式計算期間與不受理事由、整理爭點並標示依據、比對法規庫條文版本、檢索相似案例、產出決定書草稿；每項結論皆可點回原始卷證與條文。承辦人不同意時，對AI助理說一句話即產生修正提案，確認後只重算受影響步驟，草稿留版本可回溯，可匯出ODF公文。架構為一台EC2搭配Bedrock、S3、DynamoDB，最小權限、不存金鑰。以三份真實決定書反推卷宗驗證，主文、條款、期間、時效全數一致。

## English（162 words）

AppealAI is an AI case-review partner for the Legal Affairs Department's administrative appeal process. Case officers simply upload the appeal, the agency's reply, and supporting files as they are. Using Amazon Bedrock (Claude Sonnet 4.5), the system classifies documents into 27 types and renames them, then runs a fixed seven-step analysis: extract basic facts, compute deadlines and the eight inadmissibility grounds programmatically, structure the disputed issues with evidence, match statutes against a versioned law library, retrieve similar precedents, and draft the decision. Every conclusion links back to the source page or article. When an officer disagrees, one sentence to the AI assistant produces a revision proposal; after confirmation only the affected steps are recomputed, drafts are versioned, and the result exports to ODF. The stack is one EC2 instance with Bedrock, S3, and DynamoDB under least-privilege roles and no stored keys. Validated on three real decisions reconstructed into full case files: verdict, article, deadline, and limitation period all matched the actual decisions.
