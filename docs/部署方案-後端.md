# 後端部署方案

> 日期：2026-09-12　適用：`server/`（Node 20 + Express）＋ `prototype/`（靜態）
> 前提：競賽帳號、Region `us-east-1`、Bedrock ≤ 1 RPS、S3 不可 public、EC2 僅一般機型

## 1. 選服務：為什麼是 EC2，不是 Lambda／Beanstalk／ECS

| 選項 | 在允許清單 | 卡在哪 |
|---|---|---|
| **EC2 一台**（採用） | ✅ | 無。裝 poppler／LibreOffice／ffmpeg 就是 apt 三行；SSE 長連線、背景 job、單 worker 排隊都天然支援 |
| Lambda + API Gateway | ✅ | API Gateway 29 秒逾時（一箱要 40–90 秒）；REST 不支援 SSE；LibreOffice 要包 container image；冷啟動 |
| Elastic Beanstalk | ✅ | 本質還是 EC2，但要客製 platform hook 才裝得了 LibreOffice，多一層不必要 |
| ECS Fargate | ✅ | 要先 build image 推 ECR、寫 task def、開 ALB；黑客松時程不划算，正式版可換 |
| Amplify Hosting（前端） | ✅ | 可放靜態前端，但後端仍要一台；不如同一台 nginx 一起 serve，少一個 CORS 問題 |
| App Runner | ❌ 不在清單 | — |

結論：**一台 EC2 跑 nginx（靜態前端 + 反代 `/api`）+ Node 後端**；狀態在 S3 + DynamoDB，機器本身無狀態，壞了重開一台就好。

## 2. 架構

```
瀏覽器 ──HTTPS──► EC2 t3.small (us-east-1)
                   ├─ nginx :443  /        → /srv/prototype（靜態）
                   │             /api/*   → proxy 127.0.0.1:8080（SSE：proxy_buffering off）
                   └─ node server.mjs :8080（systemd，單 worker 序列跑 Bedrock）
                        │  Instance Profile（無 access key）
                        ├─► Bedrock Runtime  Converse（Sonnet 4.5 / Opus 4.5）
                        ├─► S3  appeal-cases-<acct>（private；presigned URL 給前端）
                        └─► DynamoDB  appeal-cases（單表）
```

HTTPS：demo 用 EC2 公網 IP + 自簽或 `nip.io` 免費憑證（Let's Encrypt 對 `<ip>.nip.io` 可簽）。競賽要求「Live Demo 部署網址」，`https://<ip>.nip.io` 可交。

## 3. 資源清單（交給有權限的人跑；Claude 不執行部署指令）

### 3.1 S3

```bash
ACCT=$(aws sts get-caller-identity --query Account --output text --profile hackathon)
BUCKET=appeal-cases-$ACCT
aws s3api create-bucket --bucket $BUCKET --region us-east-1 --profile hackathon
aws s3api put-public-access-block --bucket $BUCKET --profile hackathon \
  --public-access-block-configuration BlockPublicAcls=true,IgnorePublicAcls=true,BlockPublicPolicy=true,RestrictPublicBuckets=true
aws s3api put-bucket-cors --bucket $BUCKET --profile hackathon --cors-configuration '{"CORSRules":[{"AllowedOrigins":["*"],"AllowedMethods":["GET"],"AllowedHeaders":["*"],"MaxAgeSeconds":3000}]}'
```

### 3.2 DynamoDB

```bash
aws dynamodb create-table --table-name appeal-cases --region us-east-1 --profile hackathon \
  --attribute-definitions AttributeName=PK,AttributeType=S AttributeName=SK,AttributeType=S \
  --key-schema AttributeName=PK,KeyType=HASH AttributeName=SK,KeyType=RANGE \
  --billing-mode PAY_PER_REQUEST
```

### 3.3 IAM Role（Instance Profile）

`deploy/iam-policy.json`：
```json
{ "Version": "2012-10-17", "Statement": [
  { "Effect": "Allow", "Action": ["bedrock:InvokeModel", "bedrock:InvokeModelWithResponseStream"], "Resource": "*" },
  { "Effect": "Allow", "Action": ["s3:GetObject", "s3:PutObject", "s3:DeleteObject", "s3:ListBucket"], "Resource": ["arn:aws:s3:::appeal-cases-*", "arn:aws:s3:::appeal-cases-*/*"] },
  { "Effect": "Allow", "Action": ["dynamodb:GetItem", "dynamodb:PutItem", "dynamodb:UpdateItem", "dynamodb:DeleteItem", "dynamodb:Query", "dynamodb:BatchWriteItem"], "Resource": "arn:aws:dynamodb:us-east-1:*:table/appeal-cases" },
  { "Effect": "Allow", "Action": ["logs:CreateLogGroup", "logs:CreateLogStream", "logs:PutLogEvents"], "Resource": "*" }
] }
```
```bash
aws iam create-role --role-name appeal-ec2 --profile hackathon --assume-role-policy-document '{"Version":"2012-10-17","Statement":[{"Effect":"Allow","Principal":{"Service":"ec2.amazonaws.com"},"Action":"sts:AssumeRole"}]}'
aws iam put-role-policy --role-name appeal-ec2 --policy-name appeal --policy-document file://deploy/iam-policy.json --profile hackathon
aws iam create-instance-profile --instance-profile-name appeal-ec2 --profile hackathon
aws iam add-role-to-instance-profile --instance-profile-name appeal-ec2 --role-name appeal-ec2 --profile hackathon
```
> 若競賽帳號的 `WSParticipantRole` 不允許建 IAM Role（常見），退路：EC2 上 `aws configure` 放**臨時**憑證到 `~/.aws/credentials`（`.env` 留空 `AWS_PROFILE`），比賽後撤銷。不進 repo。

### 3.4 EC2

- AMI：Ubuntu 24.04 LTS（`ami-` 依 region 查）
- 機型：`t3.small`（2 vCPU / 2 GB；LibreOffice 冷啟動吃記憶體，`t3.micro` 會 OOM）；磁碟 30 GB gp3
- 安全群組：入站 22（自己 IP）、80、443（0.0.0.0/0）
- IAM instance profile：`appeal-ec2`
- User data：`deploy/ec2-userdata.sh`（下）

```bash
aws ec2 run-instances --profile hackathon --region us-east-1 \
  --image-id <ubuntu-24.04-ami> --instance-type t3.small --key-name <keypair> \
  --iam-instance-profile Name=appeal-ec2 --security-group-ids <sg-id> \
  --block-device-mappings 'DeviceName=/dev/sda1,Ebs={VolumeSize=30,VolumeType=gp3}' \
  --user-data file://deploy/ec2-userdata.sh \
  --tag-specifications 'ResourceType=instance,Tags=[{Key=Name,Value=appeal-review}]'
```

## 4. 機器上的檔案（`deploy/`，進 repo）

### 4.1 `deploy/ec2-userdata.sh`
```bash
#!/bin/bash
set -eux
apt-get update
apt-get install -y nginx poppler-utils ffmpeg file unzip git \
  libreoffice-writer libreoffice-core --no-install-recommends \
  libheif-examples fonts-noto-cjk fonts-arphic-ukai      # heif-convert；中文字型讓 odt→pdf 不缺字
curl -fsSL https://deb.nodesource.com/setup_20.x | bash - && apt-get install -y nodejs
useradd -r -m -s /bin/bash app || true
sudo -u app git clone https://github.com/KevinMursh/hackathon_wisxxxx.git /home/app/repo
cd /home/app/repo/server && sudo -u app npm ci --omit=dev
cp /home/app/repo/deploy/appeal.service /etc/systemd/system/
cp /home/app/repo/deploy/nginx.conf /etc/nginx/sites-available/appeal
ln -sf /etc/nginx/sites-available/appeal /etc/nginx/sites-enabled/appeal && rm -f /etc/nginx/sites-enabled/default
systemctl daemon-reload && systemctl enable --now appeal && systemctl restart nginx
```

### 4.2 `deploy/appeal.service`
```ini
[Unit]
Description=appeal-review backend
After=network.target
[Service]
User=app
WorkingDirectory=/home/app/repo/server
EnvironmentFile=/home/app/repo/server/.env.production   # 機器上手填，不進 repo
Environment=NODE_ENV=production PORT=8080
ExecStart=/usr/bin/node server.mjs
Restart=always
RestartSec=3
[Install]
WantedBy=multi-user.target
```

### 4.3 `deploy/nginx.conf`
```nginx
server {
  listen 80 default_server;
  client_max_body_size 500m;
  root /home/app/repo/prototype;
  index index.html;
  location /api/ {
    proxy_pass http://127.0.0.1:8080/api/;
    proxy_http_version 1.1;
    proxy_set_header Connection "";
    proxy_buffering off;            # SSE 必須
    proxy_read_timeout 3600s;
  }
  location / { try_files $uri $uri/ =404; }
}
```
HTTPS：`apt install certbot python3-certbot-nginx && certbot --nginx -d <ip>.nip.io`。

### 4.4 `.env.production`（機器上手填）
```
AWS_REGION=us-east-1
S3_BUCKET=appeal-cases-<acct>
DDB_TABLE=appeal-cases
MODEL=us.anthropic.claude-sonnet-4-5-20250929-v1:0

# AWS_PROFILE 留空 → 走 Instance Profile
```

## 5. 更新部署

```bash
ssh ubuntu@<ip> 'cd /home/app/repo && sudo -u app git pull && cd server && sudo -u app npm ci --omit=dev && sudo systemctl restart appeal'
```
前端靜態檔在同一個 `git pull` 裡一起更新，nginx 不用重啟。

## 6. 驗證步驟

1. `curl https://<host>/api/health` → `ok:true`，`tools` 全 true，`bedrock.reachable:true`
2. `curl -F files=@卷宗全卷合併.pdf https://<host>/api/cases/demo/files` → 202 + jobId
3. `curl -N https://<host>/api/jobs/<jobId>/events` → 看到 `normalized` → `box` → `result`×N → `done`
4. `curl https://<host>/api/cases/demo/files` → segments 17 段、`groups` 分組
5. `aws s3 ls s3://appeal-cases-<acct>/cases/demo/ --recursive --profile hackathon` → raw 與 normalized 都在
6. 開瀏覽器 `https://<host>/` → 前端載入（接線前仍是 mock）

## 7. 風險

- **IAM Role 建不了**：退路見 §3.3；demo 前一晚務必確認
- **t3.small 記憶體**：LibreOffice + 20 頁 pdftoppm 同時跑可能吃到 1.5 GB；`.service` 加 `MemoryMax=1.6G`，OOM 時該檔回 `NORMALIZE_FAILED` 而非機器掛
- **1 RPS 共用**：隊友若同時用同帳號打 Bedrock（KB ingestion、其他 agent），會互搶；demo 時段只跑 demo
- **磁碟**：正規化暫存在 `/tmp`，job 結束即刪；S3 是唯一持久層
