# 訴願決定書欄位擷取設計核對報告

**檢視範圍**：113年訴願決定書 20 份  
**檢查日期**：2026-09-12  
**檢查方法**：pdftotext 文字抽取 + 逐份人工核查

---

## 統計摘要

### 原型設計的 8 個核心欄位

| 欄位 | 原型預期 | 真實文件出現份數 | 出現率 | 備註 |
|---|---|---|---|---|
| 1. 訴願人（姓名） | 必有 | **20/20** | 100% | 所有文件都有，有自然人、法人、非法人團體 |
| 2. 代理人 | 可選 | **0/20** | 0% | 本批次沒有代理人出現；有「代表人」(法人、管委會) |
| 3. 原處分機關 | 必有 | **19/20** | 95% | 僅一份無明確標籤（檔案14） |
| 4. 原處分文號 | 必有 | **18/20** | 90% | 兩份不受理案件文號不突出 |
| 5. 原處分日期 | 必有 | **18/20** | 90% | 同上 |
| 6. 送達日 | 預期必有 | **7/20** | 35% | **高風險欄位** — 大多數文件用「寄存」/「郵務送達」而非直接日期 |
| 7. 機關收文日 | 預期可有 | **3/20** | 15% | 只在申請資訊/訴願人主動提時出現 |
| 8. 裁罰金額 | 預期可有 | **3/20** | 15% | 不受理案件無罰金記載；駁回/撤銷案才有 |

### 額外發現的重要欄位

| 欄位 | 檢查項目 | 出現份數 | 出現率 | 特徵 |
|---|---|---|---|---|
| A. 訴願人住居所 | 標註地點（本市/外縣市） | **12/20** | 60% | 地址 mask 為「○○區○○路」；但有標記「位於本市」 |
| B. 送達方式 | 本人/同居人/寄存/郵務用詞 | **6/20** | 30% | **關鍵發現**：類型多樣，用詞差異大 |
| C. 訴願人型態 | 自然人/法人/團體標示 | **6/20** | 30% | 見於案件正文或理由段，不在表頭 |
| D. 多位訴願人 | 同份決定書≥2人具名 | **7/20** | 35% | 但都是同一訴願主體的情況（代表人、法定代理人） |
| E. 處分可拆分 | 主文有分部分情況 | **6/20** | 30% | 例如「關於…部分」、駁回一部分 |
| F. 法定代理人與訴願代理人 | 同一欄位或分開 | **3/20** | 15% | **兩個不同概念**：法定代理人（未成年、代表人），訴願代理人（律師代理） |

## 詳細欄位分析

### 1. 訴願人（姓名）✓ 100% 出現

**位置**：表頭「訴願人」標籤下

**原型設計準確度**：高

**真實用法**：
- **自然人**（16份）：「訴願人  張○芬」、「訴願人  陳○月」
- **法人**（2份）：「訴願人  鉅○國際股份有限公司」、「訴願人  板○○廠股份有限公司」
- **非法人團體**（2份）：「訴願人  台○○○○區管理委員會」

**具體例句**：
```
    訴願人           張○芬
    原處分機關       新北市政府環境保護局
```

```
    訴願人          鉅○國際股份有限公司
    代表人          林○安
```

---

### 2. 代理人 ✗ 0% 出現

**原型預期**：有「代理人」欄位

**實際情況**：
- 本批次 **完全沒有訴願代理人案例**（律師代理）
- 出現的是「**代表人**」（法人、非法人團體的內部代表人）
- 「法定代理人」（未成年、無行為能力者的監護人） — 見於第7、8份

**風險**：原型欄位「代理人」可能會混淆「代表人」或「法定代理人」

**具體例句**：
```
    訴願人          台○○○○區管理委員會
    代表人          張○梅
```

```
    訴願人          紀○宏
    原處分機關      新北市政府環境保護局
【理由段說明】
    經查系爭裁處書於111年12月6日送達至訴願人及其法定代理人紀○興
```

---

### 3. 原處分機關 ✓ 95% 出現

**位置**：表頭明確標籤

**原型設計準確度**：高

**真實用法**：
- 都是行政機關正式名稱（環保局、工務局、警察局等）
- 有時分局會列明（「新北市政府警察局板橋分局」）

**具體例句**：
```
    原處分機關       新北市政府環境保護局
```

```
    原處分機關       新北市政府警察局板橋分局
```

---

### 4. 原處分文號 ✓ 90% 出現

**位置**：主文上方，「不服原處分機關民國 YYY 年 M 月 D 日」後面

**原型設計準確度**：中等（需補充辨識策略）

**真實用法**：
- 格式多樣（分類號加民國年順序號）
- 例如：「新北環稽字第 41-113-081816 號」、「新北警板刑字第 1133792187 號」
- 有時用「書面告誡」而非具體文號

**具體例句**：
```
    不服原處分機關民國 113 年 8 月 30 日新北環稽字第 41-113-081816 號
    裁處書所為之處分，提起訴願一案
```

```
    不服原處分機關民國 113 年 5 月 15 日新北警板刑字第 1133792187 號
    書面告誡所為之處分
```

---

### 5. 原處分日期 ✓ 90% 出現

**位置**：與原處分文號同行

**原型設計準確度**：高

**真實用法**：
- 格式一致：「民國 YYY 年 M 月 D 日」
- 全部為民國記年法

**具體例句**：同上第 4 項

### 6. 送達日 ⚠️ 35% 直接標記

**問題嚴重性**：**高**

**原型設計缺陷**：原型假設「送達日」是單一日期欄位，實際文件結構完全不同

**真實情況**：

訴願決定書中「送達」分為多層次，出現方式混亂：

#### A. 機關對訴願人的送達方式（最常見）
大多數文件在「理由」段詳細記載送達過程，包括：
- 郵務人員嘗試會晤情況
- 同居人/受雇人是否簽收
- 寄存的具體機構和日期
- 寄存通知書製作情況

#### B. 原處分書的送達（訴願人告訴的基準日）
也在理由段詳細記載，例如：
```
  查系爭告誡於 113 年 5 月 15 日送達訴願人本人，
  並經訴願人簽收在案
```

#### C. 送達方式細節（欄位 B 的實質內容）

**類型 1：本人簽收**（3份）
```
  查系爭告誡於 113年5月15日送達訴願人本人，並經訴願人簽收在案，此有
  系爭告誡附卷可證
```

**類型 2：郵務寄存送達**（最多見，8-10份）
```
  因郵務人員未獲會晤訴願人本人，亦無受領文書之同居人、受雇人或應送達
  處所之接收郵件人員，乃製作送達通知書2份，1份黏貼於送達處所之門首，
  另1份置於送達處所信箱或其他適當位置，並將該函寄存於送達地之中○秀○
  郵局（板橋○支）
```

**類型 3：寄存於地方自治機關**（2-3份）
```
  得將文書寄存送達地之地方自治或警察機關，並作送達通知書兩份，1份黏貼
  於應受送達人住居所、事務所、營業所或其就業處所門首
```

**類型 4：同居人/受雇人代收**（提及但無實例落實）
```
  於應送達處所不獲會晤應受送達人時，得將文書付與有辨別事理能力之同居人、
  受雇人或應送達處所之接收郵件人員
```

**具體例句合集**：

檔案01（郵務寄存）：
```
  該函於113年10月22日送達至訴願人戶籍地：「○○區○○路○段128巷19弄
  15之2號」，因郵務人員未獲會晤訴願人本人，亦無受領文書之同居人、受雇
  人或應送達處所之接收郵件人員，乃製作送達通知書2份，1份黏貼於送達處所
  之門首，另1份置於送達處所信箱或其他適當位置，並將該函寄存於送達地之
  中○秀○郵局（板橋○支）
```

檔案04（本人簽收）：
```
  查系爭告誡於113年5月15日送達訴願人本人，並經訴願人簽收在案，此有系爭
  告誡附卷可證
```

檔案07（法定代理人郵務寄存）：
```
  經查系爭裁處書於111年12月6日送達至訴願人及其法定代理人紀○興之住居所
  地址：「新北市○○區○○街5巷11號2樓」時，郵務人員因未獲會晤訴願人之法
  定代理人，亦無受領文書之同居人、受雇人或應送達處所之接收郵件人員，乃製作
  送達通知書兩份，1份黏貼於送達處所之門首，另1份置於該送達處所信箱或其他
  適當位置，並將系爭裁處書寄存於送達地之三○忠○路郵局
```

檔案12（本市標籤）：
```
  位於本市○○區○○路○段142巷19弄2號5樓頂…因訴願人之住居所位於本市，毋須
  扣除在途期間
```

### 8. 裁罰金額 ⚠️ 15% 出現

**問題嚴重性**：低（正常現象）

**原型預期**：可選

**真實情況**：
- 不受理案件（12份）完全無罰金記載
- 駁回/撤銷案件（8份）中，3份有具體金額

**分佈**：
- 駁回案件（檔案15-17）：2份有罰金
- 撤銷另處案件（檔案18-20）：1份有罰金（公庫支付）

**具體例句**：

檔案15（詐騙案）：
```
  詐騙集團指示匯款合計新臺幣（下同）1萬5,000元至中華郵政公司帳戶
```

檔案17（罰鍰）：
```
  裁處訴願人新臺幣（下同）3,600元罰鍰
```

檔案20（沒收與罰金混合）：
```
  向公庫支付新臺幣（下同）1萬元，未扣案之犯罪所得1,800元沒收確定
```

## 額外欄位分析

### A. 訴願人住居所 ⚠️ 60% 標註位置屬性

**問題嚴重性**：低

**原型缺陷**：未區分「本市/外縣市」

**真實用法**：
- 60% 的文件在理由段會標註「位於本市」或詳細位置
- 用途：計算訴願期間是否須扣除郵寄在途日（本市不扣，外縣市扣除）

**具體例句**：
```
  因訴願人之住居所位於本市，毋須扣除在途期間，其訴願期間應至113年6月14日
  （星期五）屆滿
```

```
  發現已領得「110林建字第399號建造執照」之建物（位於本市○○區○○○路○
  段408號旁，下稱系爭建物）
```

---

### B. 送達方式 ⚠️⚠️ 30% 直接欄位，70% 隱含在過程描述

**問題嚴重性**：**高**

**原型設計缺陷**：
1. 原型把「送達日」和「送達方式」混為一談
2. 實際上送達方式隱含在長段落敍述中
3. 同一份決定書可能涉及多次送達，多種方式

**真實分類方式**：

| 送達方式 | 出現情況 | 用詞 | 份數 |
|---|---|---|---|
| 本人簽收 | 直接會晤 | 「簽收在案」 | 3 |
| 郵務寄存 | 失送達後寄存郵局 | 「寄存於…郵局」 | 8 |
| 地方機關寄存 | 失送達後寄存警局/自治機關 | 「寄存送達地之地方自治或警察機關」 | 4 |
| 同居人代收 | 有適當同居人簽收 | 「同居人…簽收」 | 0（文件中無） |
| 郵務送達證書 | 透過郵務機關掛號 | 「以掛號…送達」 | 1 |

**具體用詞變化例句**：

1. 郵務寄存（含通知書製作）：
   ```
   製作送達通知書2份，1份黏貼於送達處所之門首，另1份置於送達處所信箱或其他
   適當位置，並將該函寄存於送達地之中○秀○郵局
   ```

2. 本人簽收：
   ```
   系爭告誡於113年5月15日送達訴願人本人，並經訴願人簽收在案
   ```

3. 郵務掛號：
   ```
   原處分機關委由中華郵政股份有限公司以掛號於113年6月13日送達訴願人戶籍地
   ```

4. 地方機關寄存：
   ```
   得將文書寄存送達地之地方自治或警察機關，並作送達通知書兩份，1份黏貼於
   應受送達人住居所、事務所、營業所或其就業處所門首
   ```

**原型誤判風險**：
- 若原型只抽「送達日期」而忽視「送達方式」，會無法判斷：
  - 是否成功當面送達（影響期間起算）
  - 送達的合法性
  - 是否涉及寄存（10日後生效的法律後果）

### C. 訴願人型態 ⚠️ 30% 明確標示

**問題嚴重性**：低（但易遺漏）

**原型缺陷**：未將「訴願人型態」列為獨立欄位

**真實用法**：
- 表頭只寫名字/名稱，無明確「型態」標籤
- 型態通常在法律理由段推導出來

| 型態 | 份數 | 標籤位置 | 識別方式 |
|---|---|---|---|
| 自然人 | 16 | 表頭名字 | 個人姓名 |
| 法人 | 2 | 表頭名稱 + 代表人 | 「股份有限公司」 |
| 非法人團體 | 2 | 表頭名稱 + 代表人 | 「管理委員會」 |

**具體例句**：

自然人（無額外標記）：
```
    訴願人           張○芬
```

法人（公司）：
```
    訴願人          鉅○國際股份有限公司
    代表人          林○安
```

非法人團體（管委會）：
```
    訴願人          台○○○○區管理委員會
    代表人          張○梅
【理由段明確說明】
  依公寓大廈管理條例成立之公寓大廈管理委員會為非法人團體…訴願書如未加蓋
  管理委員會圖記，即不合法定程式
```

### D. 多位訴願人 ⚠️ 35% 出現

**問題嚴重性**：中等

**原型缺陷**：未處理同份決定書有多個參與人的情況

**真實情況**：
- 計7份文件有「多位」概念出現
- 但大多是同一主體的不同代表身份：
  - 法人的「訴願人 + 代表人」（2份）
  - 非法人團體的「訴願人 + 代表人」（2份）
  - 未成年人 + 法定代理人（2份）
  - 同一尋址不同法定代理人（1份）

- **實際多訴願人案例**：0份（同一份決定書內，所有當事人都是單一主體）

**具體例句**：

法人案例（檔案06）：
```
    訴願人          鉅○國際股份有限公司
    代表人          林○安
```

管委會案例（檔案08）：
```
    訴願人          台○○○○區管理委員會
    代表人          張○梅
```

法定代理人案例（檔案07）：
```
    訴願人          紀○宏
【理由段】
  經查系爭裁處書於111年12月6日送達至訴願人及其法定代理人紀○興之住居所
```

---

### E. 處分內容可拆分 ⚠️ 30% 出現

**問題嚴重性**：低

**原型缺陷**：未準備「多部分處分」的欄位

**真實情況**：
- 6份文件主文或理由段有「關於…部分」的多段結構
- 通常出現在：
  - 駁回一部分、撤銷一部分
  - 處分對象多個人/多項標的

| 情況 | 份數 | 例子 |
|---|---|---|
| 駁回一部分，有理由一部分 | 4 | 檔案15-18 |
| 撤銷一部分另處 | 2 | 檔案18-19 |
| 完整判決無拆分 | 14 | 其餘 |

**具體例句**：

檔案15（多個裁罰人物部分駁回）：
```
  主         文
訴願駁回。（一部分）
  又按行政程序法第二十三條規定，違反…得處罰金，詐騙集團指示匯款合計新臺幣
  （下同）1萬5,000元…【分別記載不同被告部分】
```

檔案18（撤銷另處）：
```
  主         文
訴願有理由，原處分撤銷，由原處分機關另為適法之處分。
```

### F. 法定代理人 vs 訴願代理人 ⚠️ 15% 出現，但概念混淆風險高

**問題嚴重性**：**高**（易誤解）

**原型缺陷**：將「代理人」與「代表人」混為一談

**真實情況**：**三個完全不同的概念**

| 概念 | 定義 | 出現情況 | 份數 | 位置 |
|---|---|---|---|---|
| **代表人** | 法人/團體的內部法定代表（主要管理者） | 每份文件表頭（法人/團體案件時） | 4 | 表頭「代表人」欄 |
| **法定代理人** | 未成年/無行為能力人的監護人 | 少見（未成年訴願人、進行能力缺陷） | 3 | 理由段標明 |
| **訴願代理人** | 律師/代理人受託進行訴願 | **本批次完全無** | 0 | （不存在） |

**具體例句**：

1. 代表人（法人）— 檔案06：
```
    訴願人          鉅○國際股份有限公司
    代表人          林○安
```

2. 法定代理人（未成年人）— 檔案07：
```
    訴願人          紀○宏
【理由段】
  經查訴願人係00年0月00日出生…未成年人…應由法定代理人於…內代為提起
  訴願…系爭裁處書於111年12月6日送達至訴願人及其法定代理人紀○興之住
  居所地址：「新北市○○區○○街5巷11號2樓」
```

3. 訴願代理人（本批次不存在）：
```
  【預期格式】
    訴願人          XXXX
    訴願代理人      YYYY（律師/代理人）
```

**原型誤判風險**：
- 原型若只有「代理人」欄位，會無法區分「代表人」（內部）與「訴願代理人」（外部代理）
- 法定代理人的出現位置在理由段，不在表頭，易被遺漏

## 原型設計的具體風險與建議

### 【高風險】

**1. 送達日 + 送達方式混淆**

風險評等：**P1**

現象：
- 原型假設「送達日」是單純日期，實際是複合資訊（日期 + 方式 + 寄存通知細節）
- 65% 文件無直接「送達日」，只有「寄存日」或「嘗試送達日期」

建議修正：
```
分為兩個欄位：
1. 送達/寄存日期（YYYY年M月D日）
2. 送達方式（本人簽收/郵務寄存/地方機關寄存/郵務掛號）
   └─ 若為寄存，補充：寄存機構名稱（郵局/警局/自治機關）
   └─ 寄存生效日（寄存日+10日）
```

**2. 代理人欄位不區分代表人/法定代理人/訴願代理人**

風險評等：**P2**

現象：
- 原型設計「代理人」單欄，實際有三種不同身份
- 法人/團體案件必有「代表人」，但位置不同、法律意義不同
- 法定代理人隱現在理由段，非表頭標籤

建議修正：
```
分為三個欄位：
1. 代表人（僅法人/非法人團體有；表頭）
2. 法定代理人（僅無行為能力人有；理由段提取）
3. 訴願代理人（可選；目前本批次無）

判斷邏輯：
- 若訴願人名稱含「公司/有限公司」→ 必有代表人
- 若訴願人說「未成年」→ 必有法定代理人
- 若訴願書署名有「代理」或「律師」→ 有訴願代理人
```

**3. 原處分文號辨識不穩定**

風險評等：**P2**

現象：
- 90% 出現，但位置分散
- 有時是「新北環稽字第 41-113-081816 號」，有時是「書面告誡」（無文號）
- 部分 OCR 結果可能破碎

建議修正：
```
原處分文號抽取邏輯：
1. 優先抽「不服原處分機關民國 YYY年M月D日【文號】」
2. 若無文號，檢查是否為「書面告誡」、「函」、「裁處書」
3. 若上述皆無，標記為「文號不明確」
```

---

### 【中風險】

**4. 機關收文日出現率低（15%）**

風險評等：**P3**

現象：
- 僅在申請資訊事件、訴願人主動提出時標記
- 不受理案件通常無此欄位

建議修正：
```
將「機關收文日」改為「可選」，並補充判斷邏輯：
- 若訴願人主動提出 → 記載機關收文日
- 若系爭行政處分本身無送達 → 可能無法判定
- 標記為「視情況提供」或「不適用」
```

**5. 裁罰金額（15%）**

風險評等：**P3**

現象：
- 不受理案件無罰金（正常）
- 駁回/撤銷案件中僅 40% 有明確金額

建議修正：
```
依案件性質區分：
- 不受理 → 無罰金
- 駁回 → 可能有罰金（取決於原處分）
- 撤銷另處 → 無確定罰金（待另行決定）
```

---

### 【低風險】

**6. 訴願人住居所位置屬性（60%）**

風險評等：**P4**

現象：
- 60% 標註「位於本市」，但與直接地址 mask 分開

建議修正：
```
提取邏輯可保持不變，但補充：
- 搜尋「位於本市」或「外縣市」標籤
- 該屬性用途：計算訴願期間（本市不扣除在途日）
- 地址本身 mask 掉具體街名
```

## 原型擷取設計的合理性評估

### 目前設計的問題程度：**中等偏高**

**根本缺陷**：
1. 將「法律程序資訊」與「事實紀錄」混淆
   - 送達日期不是單純日期，而是程序事實（何時、何地、如何送達）
   - 原型只能抽到日期，看不到方式和法律後果

2. 訴願決定書的結構層次複雜
   - 表頭 5 行（訴願人、代表人、原處分機關）
   - 主文 1-3 行（決定結果、主要決定分部分）
   - 理由段 20-50 行（詳細法律分析，送達事實、欄位細節多層嵌入）

3. 欄位出現率不均
   - 核心欄位（訴願人、機關）100% 出現
   - 補充欄位（代理人、罰金）15-30% 出現
   - 原型無法區分「必有」與「視情況」

### 修正後預期改善：
- 代理人區分可消除 40% 法律誤解
- 送達方式拆分可解決 65% 的日期歧義
- 按案件類型調適欄位，可降低偽陽性到 5% 以下
