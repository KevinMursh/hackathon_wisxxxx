# 案件相關資料卷宗類型討論

日期：2026-09-12
起因：訴願書、答辯書之外，案件卷宗還有哪些文件？從 101 份決定書理由段「此有……附卷可稽」的實際引用中萃取，非臆測。
關聯：`01-情境走查缺漏總表.md` 的 C3（卷證清單逐項勾收）、E3（職權調查/調卷模組）兩項缺漏，此文補上具體文件類型清單。

---

## 結論一句話

訴願書、答辯書只是「起訴狀」跟「答辯狀」；決定書理由段的證據引用，才是卷宗全貌。「案件相關資料卷宗」不是固定格式，是**依案件類型變化的證據清單**——系統要準備的不是兩種 parser（訴願書/答辯書），而是一個**通用文件分類器**，先判斷「這份附件是什麼類型」，再決定擷取邏輯。

---

## 卷宗常見文件類型（依來源分類，全部有 101 份決定書實據）

### A. 原處分機關這邊產生的

| 類型 | 實例（原文引用） |
|---|---|
| 原處分書／裁處書／告誡書 | 訴願法 §56 II 規定訴願書本身就要附這個影本 |
| 送達證書 | 「訴願人戶籍資料、系爭補正通知函及其送達證書等影本附卷可稽」（19 份出現）|
| 稽查／勘查紀錄表 | 「113年8月18日臨檢紀錄表、現場勘查照片數幀」 |
| 現場採證照片／監視器影片 | 「此有採證照片及影片附卷可稽」「稽查紀錄及錄影採證照片」 |
| 檢查報告書 | 建築物公共安全檢查案：「111年檢查申報案之檢查報告書」 |
| 專案小組會議紀錄 | 同案：「召開專案小組會議決議」——機關內部認定程序的紀錄 |
| 裁罰基準／附表（獨立文件） | 20 份決定書文末掛「相關圖表：附表.PDF」 |
| 簽稿／內部簽呈 | 「1134082840號簽稿等影本」 |

### B. 訴願人這邊提交的

| 類型 | 實例（原文引用） |
|---|---|
| 委任狀／授權書 | 有訴願代理人的案子才有 |
| 戶籍謄本 | 中低收入戶範例訴願書明載附送 |
| 土地/建物登記謄本、使用執照 | 建照/既成道路類案件 |
| 公司登記資料 | 分公司/總公司訴願能力判斷用（見 S04 情境）|
| 不起訴處分書／刑事判決 | 洗錢防制法案：「檢察署起訴書、系爭刑事判決等影本」 |
| 警詢筆錄／帳戶交易紀錄 | 洗錢防制法案：「訴願人警詢筆錄、帳號交易紀錄」 |
| 陳情案件明細 | 陳情類案件：「本府人民陳情案件明細、系爭回覆說明書」 |

### C. 委員會審理過程中自己產生/調取的

| 類型 | 依據 |
|---|---|
| 前案決定書（比對 77⑦ 重行提起用） | 需調閱同一訴願人的歷史案件 |
| 職權調查函與回文 | 訴願法 §67，委員會主動向其他機關調卷 |
| 陳述意見紀錄／言詞辯論筆錄 | §63、§65，訴願人申請或委員會認有必要 |
| 鑑定報告 | §69，少見，技術性爭點才用到 |
| 審議紀錄 | §54，委員會內部決議紀錄，不對外 |

## 對系統設計的意涵

1. **文件擷取前處理層不能只認訴願書/答辯書兩種格式**，要先過一層「文件分類器」判斷附件類型（原處分書/送達證書/照片/謄本/筆錄/前案決定書……），再分派給對應的擷取邏輯。
2. **證據類型隨案件類型變化**：洗錢防制案吃警詢筆錄/交易紀錄，建築案吃檢查報告書/使用執照，陳情案吃陳情明細——擷取 schema 不能是單一固定表單，要按案件類型（洗防/廢清/建築/空污/噪音/陳情……）掛不同的卷證期待清單。
3. **多格式輸入**再次確認必要：這些文件形式橫跨 PDF公文、照片、Excel附表、掃描謄本，OCR/文件解析層要能吃全部。
4. 呼應 `01-情境走查缺漏總表.md` C3「卷證清單逐項勾收 → 決定書『此有…附卷可稽』的來源」——現在這份清單提供了具體的證據類型枚舉，可以直接拿去設計 Rules 畫面的「卷證清單」欄位選單。
