## 欄位原文例句

### 1. 訴願人

文件格式固定，出現位置在表頭：

```
訴願人          戴○任
訴願人          劉○謙
訴願人          黃○毅
```

### 2. 代理人（出現 5 份）

`代理人` 與 `法定代理人` 在文件中為分開的欄位。例句：

```
訴願人          陳○勳      代理人          陳○璇
```

**說明**：代理人欄在訴願人下一行，但僅在有代理人時才出現。

### 3. 法定代理人（出現 1 份）

法定代理人與代理人為不同欄位：

```
0 條規定：「無訴願能力人應由其法定代理人代為訴願行為
```

### 4. 原處分機關（出現 18 份）

```
原處分機關            新北市政府環境保護局
原處分機關            新北市政府工務局
原處分機關            新北市政府農業處
```

### 5. 原處分文號（出現 20 份）

包含在敘述文中，如：

```
新北環稽字第 00-000-000075 號裁處書所為之處分
新北工使字第 1111564484 號函併附同文號處分書所為之處分
新北府訴決字第 1112160532 號
```

### 6. 原處分日期（出現 20 份）

```
民國 111 年 10 月 19 日
民國 111 年 3 月 15 日
民國 111 年 8 月 19 日
```

### 7. 送達日（出現 17 份）

通常在補正通知段落或送達證書內容中：

```
於 111 年 11 月 11 日送達至訴願人之住所
郵務人員於 111 年 12 月 13 日至訴願人住所嘗試送達
```

### A. 住居所（出現 7 份）

文件中記錄具體地址（已遮蔽個資）：

```
新北市○○區○○路○段 221 巷 30 號 2 樓
新北市○○區○○路○段 1 號 1 樓
```

**是否標記本市/外縣市**：部分檔案略。本批樣本未明確見到「本市」「外縣市」標記。

### B. 送達方式（出現 7 份，變異多）

實務中常見的送達方式用語：

```
1. 同居人代收：
   由該應送達處所之受雇人即社區管理人員於送達證書上簽章及蓋有該社區警衛室收發章以示簽收

2. 寄存送達：
   得將文書寄存送達地之地方自治或警察機關，並作送達通知書兩份，一份黏貼於應受送達人住居所

3. 郵務寄存：
   因郵務人員均未獲會晤訴願人本人亦無受領文書之同居人、受雇人或應送達處所之接收郵件人員，
   遂依法寄存於山○郵局
```

**關鍵詞彙變化**：簽收、代收、寄存、郵務寄存等用語混用，無統一欄位標記。

### C. 訴願人型態（出現 6 份）

```
自然人：訴願人          戴○任

法人：「…自然人、法人、非法人之團體或其他受行政處分之相對人

分公司：「…分公司係總公司分設之獨立機構，就其業務範圍內之事項涉訟時

管委會：訴願人及管委會一同知悉並圖示位置

團體：團體或其他受行政處分之相對人及利害關係人
```

**現況**：型態資訊散布在敘述文中，無獨立欄位。

### D. 多位訴願人（出現 1 份）

部分案件含多件裁處書或多位當事人：

```
上列訴願人等因違反廢棄物清理法事件，不服原處分機關民國 111 年 10 月 5 日
新北環稽字第 00-000-000002 號等 24 件裁處書（詳如附表）所為之處分
```

**現況**：訴願人欄為單人單列，無法在欄位層面記錄多位訴願人或多件案件關聯。

### F. 代理人欄位分化（出現 2 份）

法定代理人與訴願代理人在條文引用中被區分：

```
法定代理人：「無訴願能力人應由其法定代理人代為訴願行為」

訴願代理人：「訴願應具訴願書，由訴願人或代理人簽名或蓋章」
```

**現況**：表頭欄只有單一「代理人」，無法區分法定 vs. 訴願代理。

## 設計風險評估

### 1. 高風險項目

#### 1.1 送達方式無統一欄位 ⚠️ 高風險

**現況**：
- 原型設計：僅「送達日」(單一日期欄位)
- 真實文件：送達方式有 7 種組合變異（簽收/代收/寄存/郵務寄存等）
- 出現比率：17 份文件含「送達」紀錄，其中 7 份明確記錄方式

**風險具體化**：
- 訴願逾期認定：須檢查送達方式判定送達日點 (同居人代收 vs. 寄存送達時點不同)
- 原型無法區分：無法自動判斷逾期依據是「簽收日」還是「寄存通知日」
- 誤判案例：若只抓送達日，可能誤判補正期限起算點

**建議修正**：
```
送達日期      [日期]     →  需新增欄位
送達方式      [下拉選單] →  同居人代收 / 本人簽收 / 寄存送達 / 郵務寄存
```

#### 1.2 代理人型態未分化 ⚠️ 中風險

**現況**：
- 原型設計：單一「代理人」欄
- 真實文件：區分「法定代理人」(1份) 與「代理人」(5份) 與「代表人」(4份)

**法律後果**：
- 法定代理人代理無訴願能力人 → 決定程序合法性條件
- 訴願代理人代理自然人 → 代理授權效力判定
- 代表人代理法人 → 當事人能力判定

**風險**：混淆三者會影響當事人適格判定

#### 1.3 多位訴願人無法關聯 ⚠️ 中風險

**現況**：
- 樣本中有 1 份含「等 24 件裁處書」，意即多件案件、可能多位訴願人
- 原型欄位：訴願人 (20/20) 為單欄單列

**風險**：複雜案件無法在結構化欄位層面記錄「案件A由甲訴願、案件B由乙訴願」

### 2. 中風險項目

#### 2.1 裁罰金額覆蓋率低 ⚠️ 中風險

**現況**：
- 出現比率：1/20 (5%)
- 原因：本批樣本多為「不受理」決定，無實體審查故無罰金

**設計建議**：
- 該欄位在「駁回」「撤銷」決定才有意義
- 本批樣本不足以驗證實裝穩定性

#### 2.2 機關收文日出現率低 ⚠️ 低風險

**現況**：
- 出現比率：1/20 (5%)
- 通常在補正通知時標記，不受理案件不會強調

### 3. 低風險項目

#### 3.1 原處分機關漏 2 份 ✓ 低風險

**現況**：
- 出現比率：18/20 (90%)
- 漏掉的 2 份為「申請閱覽卷宗」「陳情」類案件，原本無原處分

**評估**：非設計缺陷，是案件類型特性

#### 3.2 原處分文號與日期完整 ✓ 低風險

**現況**：
- 出現比率：20/20 (100%) 各自獨立
- 設計與現實完全貼合

## 結論與建議

### 原型需補強 3 個隱藏欄位

1. **送達方式** (高優先) → 新增下拉選單欄，選項：同居人代收/本人簽收/寄存送達/郵務寄存
2. **代理人型態分化** (中優先) → 將單一「代理人」拆為「法定代理人」「訴願代理人」「代表人」
3. **多位訴願人表示** (中優先) → 考慮案件表關聯，或在訴願人欄允許複選

### 原型可維持現狀的 3 個欄位

- ✓ 原處分文號、日期、機構 → 覆蓋率高且結構清晰
- ✓ 裁罰金額 → 現狀可用，低頻欄位

### 驗收清單

- [ ] 實作時限：預計本批決定書擷取需加入送達方式欄
- [ ] 測試集：建議新增「駁回」「撤銷」案件 5-10 份，驗證裁罰金額欄穩定性
- [ ] 代理人分化：確認是否需要三欄分離或保留單欄備註
