## 驗收過程修掉的 bug（都已上線）

1. `analysis-proxy.mjs`：POST 帶 JSON body 只轉發 content-length 不送 body → objection／chat 全卡
2. Node `GET /api/jobs/:id` 先攔走 Python job → 提案確認改輪詢 `GET proposal`
3. `revised_finding` 非三值（「採機關（補強法條引用）」）→ 正規化
4. proxy 少 `preview` 路徑
5. 模型把整段內容塞進 `para` → 對回段落標籤
6. 「理由二精簡」被反問 → prompt 明示已指名段落即明確對象，摘要附 draft_paras
7. **補件的 `addFiles` 覆蓋首頁上傳的 `addFiles`（v10 起首頁真上傳失效）** → 改名 `addSupplement`
8. 另存新草稿殘留法院結果；送審後補件鈕未停用；判定條空括號
9. 法規庫仍是 mock 回放 → 接真 API
