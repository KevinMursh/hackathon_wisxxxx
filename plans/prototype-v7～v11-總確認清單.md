## G. mock 與正式版的界線（給評審與後端）

| 現在（mock） | 正式版 |
|---|---|
| 意圖解析用關鍵字規則 | 模型呼叫 `propose_revision` 工具吐同結構 |
| 草稿 diff 預覽用預建方案 | 先跑一次「預覽草稿」（只重產受影響段落、不落地）再畫 diff |
| 補件辨識用檔名關鍵字 | Node 歸戶 API 看內容判定（27 種 doc_type、5 種 source） |
| 原地重跑用 setTimeout 動畫 | SSE 逐步事件驅動同一套 UI |
| 法規庫同步按鈕回放 lawsync 結果 | 後端排程 `lawsync.py` → S3 → KB ingestion，前端讀 `runs/lawsync.json` |
