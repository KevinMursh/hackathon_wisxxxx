## 1. 清單

1. ☑ 移除修正意見表單、爭點旁連結、Tab5 按鈕
2. ☑ 助手加寬（600px）；標題「案件助手・問答唯讀・修改須經您確認才執行」
3. ☑ 意圖解析（mock NLU）：爭點 N 改採○／刪除、加引／移除 ○法第 N 條第 N 項、送達日改 日期、進入實體／依 77(N) 不受理、結論改撤銷／駁回、理由N 精簡／語氣、從○角度
4. ☑ 法規名稱比對：全名或別名（裁罰準則）→ 法規庫；條號超出即 ✗
5. ☑ 提案卡：逐項元件預覽＋草稿 diff 預覽（主文、理由優先，最多 2 段）＋影響範圍
6. ☑ 卡內「查看 ↗」跳分頁／爭點
7. ☑ 確認 → 局部重跑 → 已執行卡；取消 → 灰化＋反問
8. ☑ 法條問答附「以此提出修改 →」，點了自動送「請加引…」
9. ☑ 送達日更正實際重算期間；爭點採納實際改方案與草稿版本
10. ☑ 全站字樣：修改提案／修改 N 次
