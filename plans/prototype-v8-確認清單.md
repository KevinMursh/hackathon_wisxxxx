# 訴願智審臺 Prototype v8 確認清單　— 「修正意見」取代「我有異議」

> 日期：2026-09-12　範圍：只改 `prototype/`（全部 mock）；問答助手另案於 pipeline 實作
> 狀態標記：☐ 待做　☑ 完成

## 0. 已拍板

| 決定 | 內容 |
|---|---|
| 名稱 | 按鈕「提出修正意見」、視窗「修正意見」；AI 回覆維持採納／部分採納／無法採納 |
| 六類意見 | 事實欄位／程序判定／爭點認定（可多個）／法規引用／論述架構或結論／文字表達，全部選填 |
| 客製化指示 | 大型自由文字框，承載欄位未涵蓋的需求（可貼法條、判決、改寫角度） |
| 送出條件 | 任一項有內容即可 |
| 影響範圍 | 依意見類型算出「重新產生」與「維持不變」的分頁（mock triage，客製化指示用關鍵字判斷）；可切「全部重跑」 |
| 重跑 | 只重跑受影響分頁，未受影響分頁原樣保留；AI 逐項回覆 |

## 1. 清單

1. ☑ 所有「異議」字樣改「修正意見」（按鈕、爭點頁連結、chip、紀錄表、助手提示）
2. ☑ 視窗改三段：類型複選 → 逐項面板 → 客製化指示＋引用卷證 → 影響範圍
3. ☑ 爭點認定：每個爭點可勾選，選「採訴願人／採機關／刪除此爭點」＋理由；可新增爭點
4. ☑ 法規引用：法規（自法規庫下拉）＋條＋項，即時查核：法規庫有／查無／條號超出
5. ☑ 事實欄位：選欄位＋正確內容；送達日修改會實際重算期間
6. ☑ 程序判定：進入實體／依 §77 各款不受理
7. ☑ 論述架構或結論：結論下拉（AI 判定或其他方案）＋角度／篇幅說明
8. ☑ 文字表達：選段落＋指示
9. ☑ 影響範圍列由勾選類型與客製化指示即時算出，附「全部重跑」切換
10. ☑ 送出：進處理畫面，只跑受影響步驟（未受影響標「維持」）；回到草稿頁顯示逐項回覆
11. ☑ 版本、稽核、案件庫紀錄、送審比對表相容
