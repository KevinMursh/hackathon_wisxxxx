## 刻意留下的測試點

1. **時效是決勝點，且證據齊全**：起算日（111/6/9，訴願書附件三、卷證 07）、處分日（114/7/4，卷證 01）、送達日（114/7/9，卷證 02）
   都在卷內，系統應自行驗算 3 年，得出裁處權已消滅 → 撤銷。
2. **答辯書沒有正面回應時效**：只說「容有一併審酌之必要」和「複查時始發現」——後者在法律上無效（§27 II 自行為終了起算，不是自發現起算）。
   系統不應把「機關發現日」當起算點，也不應因答辯書迴避就略過這個爭點。
3. **機關實體事證其實很強**：複查紀錄、照片、專案小組決議、竣工圖都指向簽證確有不實，決定書也承認「固非無據」。
   系統應寫出「實體上固非無據，惟時效已消滅」的結構，而不是判「駁回」（被實體證據帶走）或判「訴願人簽證沒問題」（採納訴願人實體抗辯）。
4. **撤銷 vs 撤銷另處**：時效消滅 → 機關不能再處分 → 主文只寫「原處分撤銷」，**不加**「由原處分機關另為適法之處分」，**不附**救濟教示。
5. **簽呈法制欄的批註**：「時效請併審酌」是機關內部已有人警覺的線索；系統若能在爭點分析中指出，屬加分。
6. **收受日不一致**：訴願書自述 7/4（發文日），送達證書 7/9；以送達證書為準。本案兩者皆在期間內，是「衝突但不影響結論」的樣本。
7. **形式混雜**：文字 PDF、掃描 JPG（含手寫、彩色核章）、系統截圖、SVG 圖說、2 幀照片。
