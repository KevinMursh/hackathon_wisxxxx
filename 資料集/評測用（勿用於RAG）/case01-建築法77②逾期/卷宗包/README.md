## 這是什麼、不是什麼

- **是**：依《訴願法》58 條 III（檢卷答辯）、14 條（期間）、《行政程序法》72／74 條（送達）、102 條（陳述意見）
  與建管稽查實務，推導出「這個案子的卷宗**法律上必然存在**哪些文件」，再逐份製作。
- **不是**：真實卷宗。每頁均有「黑客松測試用模擬文件」浮水印，印文標示「（模擬）」，個資全數遮蔽或虛構。
- **實體案情是模擬的**：真實決定書因程序不受理，理由段完全未提違規態樣。本包以「建築法 §73 II
  未經核准變更使用（H-2 住宅 → B-3 小吃店），依 §91 I ① 處 6 萬元」為模擬案情，
  用來讓答辯書有備位實體答辯、讓卷證有勘查紀錄與照片可比對；**標準答案（77② 不受理）不受影響**。
- 決定書本身（標準答案）**不在**本包內，且**須自 RAG／向量庫排除**（見上層 README）。

## 刻意留下的測試點

1. **程序優先於實體**：訴願書花了六點理由講實體（自住、聚會、比例原則），答辯書備位也答了實體，卷證還有勘查照片；
   但正確結論是 **§77② 不受理，根本不進實體**。系統不應被大量實體材料帶偏而去寫「駁回」或「撤銷」。
2. **期間計算的三個數字都在卷內**：送達日（02 送達證書 8/24）、收文日（訴願書末頁收文戳／答辯附件二 9/30）、
   設籍地（答辯附件三、02 送達處所）。系統應自行驗算：8/25 起算 → 9/23 屆滿 → 逾 7 日，而非只抄答辯書。
3. **兩張送達證書、兩種送達方式**：02 是處分書「交付本人」，06 是陳述意見通知書「寄存送達」。
   期間起算只看 02；系統若誤用 06 的寄存日或誤套寄存規則，即為錯誤。
4. **訴願書理由五的「遲誤說明」**：訴願人稱因年邁、蒐集資料費時而遲提——這不構成訴願法 §15 回復原狀
   （非天災或不可歸責事由，也未申請）。系統應辨識並在理由中一併處理，而非視為有效抗辯。
5. **訴願書日期 vs 收文日**：訴願書落款 9/30、收文戳 9/30，本案一致；但委任書落款 9/28、照片 9/20、
   切結書 9/26——這些都不是「提起日」，提起日以機關收文為準（訴願法 §14 III）。
6. **形式混雜**：文字 PDF、掃描 JPG（含 2 份手寫、1 份彩色核章）、4 份系統截圖、2 幀照片。
7. **個資遮蔽方式與真實決定書一致**（○ 遮字、A1****7752、○○區），OCR 後不應把「○」當成錯字修正。
